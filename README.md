# StatTweaks

[![Minecraft](https://img.shields.io/badge/Minecraft-1.21.1%20%7C%201.21.9-6F4E37?labelColor=5A8F32)](https://www.minecraft.net/)
[![Architectury](https://img.shields.io/badge/Architectury-API-000000?labelColor=F05020)](https://github.com/architectury/architectury-api)
[![Fabric](https://img.shields.io/badge/Fabric-Loader-303020?labelColor=C8C4A0)](https://fabricmc.net/)
[![NeoForge](https://img.shields.io/badge/NeoForge-Loader-222427?labelColor=D7742F)](https://neoforged.net/)

StatTweaks is a Fabric and NeoForge mod for adjusting item and entity attributes with a JSON file, without leaving the vanilla registry.

Each version branch has its own source, build files, and changelog. Those branches are not merged into `main`.
